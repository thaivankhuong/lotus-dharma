# LD-0001 - Add Google Login API

## Goal
Implement Google OAuth2 login using Google.Apis.Auth and integrate it with existing JWT authentication in the LotusDharma Backend (.NET 9, CleanArchitecture).

---

## Architecture Rules
- Follow Jason Taylor CleanArchitecture structure:
  - Domain: Entities, Enums, Events
  - Application: Handlers, DTOs, Interfaces
  - Infrastructure: Persistence and external service integrations
  - WebApi: Controllers and configuration
- Use MediatR for CQRS.
- All code and comments must be in English only.
- Respect SOLID principles.

---

## Requirements
1. Create a new Identity module to handle user authentication and registration.
2. Implement Google OAuth2 login endpoint: POST /api/auth/google
3. Use Google.Apis.Auth to validate Google ID tokens.
4. If the user exists → return JWT. If not → create a new user and return JWT.
5. Add JWT Authentication configuration in appsettings.json.
6. Create JwtService to generate access tokens.
7. Store refresh tokens (define structure; implementation optional for now).
8. Use Google Client ID from environment variables.

Example config (place in appsettings.json or environment variables):

    "Jwt": {
        "Key": "your-secret-key",
        "Issuer": "LotusDharma",
        "Audience": "LotusDharmaUsers",
        "ExpireMinutes": 60
    }

    "GoogleAuth": {
        "ClientId": "your-google-client-id"
    }

---

## User Entity Definition (for Identity module)
Each user created via Google login must contain the following fields:

| Field | Type | Description |
|-------|------|-------------|
| Id | Guid | Primary key |
| Email | string | User’s Google email (unique, used as username) |
| FullName | string | Display name from Google payload |
| PictureUrl | string | Profile image URL |
| Provider | string | Authentication provider (e.g., "Google", "Local") |
| ProviderId | string | Google’s unique user ID (sub field from payload) |
| Role | string | Default = "User" |
| IsActive | bool | Indicates if account is active |
| CreatedAt | DateTime | Creation timestamp |
| UpdatedAt | DateTime | Last update timestamp |
| LastLoginAt | DateTime? | Last login timestamp |
| PasswordHash | string? | Null for Google login |
| Salt | string? | Null for Google login |

> The system should store Google user information in the Users table using the fields above.  
> For Google login, PasswordHash and Salt must remain null.
